HVG isolation test — does high-variance gene selection add biology, or just crisp the picture?

MiniFin comp-8 (entangled endoderm: Ionocyte / Goblet), frozen 1,537-cell membership. Both arms branch from the identical coarse-Leiden-0.1 compartment set — only the gene-selection step differs. GT scored on the 176 control (DMSO) + labelled cells at the end.

Verdict — Darien confirmed ✅

HVG is geometrically crisper (silhouette +0.062, Davies–Bouldin better) but tissue purity sits within σ (Δ0.034 < 0.069 gate) and, if anything, favours no-HVG (0.960 vs 0.926). The extra crispness is cosmetic geometry, not added biology.

Caveats

  • Small GT N — 176 control+labelled cells; the σ=0.069 gate exists precisely so a ~6-cell wobble isn't credited as signal.
  • Effectively a 2-type contrast — Ionocyte vs Goblet; both arms already separate it well (0.93–0.96), the cleanest possible crispness-vs-biology test.
  • One compartment, one dataset — comp-8 only. The other 17 compartments are gated, not fired.
