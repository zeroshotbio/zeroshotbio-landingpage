HVG isolation test — does high-variance gene selection add biology, or just crisp the picture?

Darien asked whether the per-compartment HVG recompute in our recursive recipe is doing real work or just cosmetics. comp-8 (a shared-program, already-separated case) said “cosmetic — geometry only.” We predicted that distinct-program compartments would flip — that fresh local features would be what surfaces a buried marker program. This note is that test, run broad across ZSCAPE. The prediction did not hold — and that’s the headline.

prediction falsified

No-HVG matches or beats HVG on purity across every distinct-program compartment.

We ran HVG (Arm A) vs no-HVG (Arm B) on the compartments where Pillar 1 says local HVG is load-bearing — Blood, Pancreas, Intestine, Ear/otic, Olfactory, inside ZSCAPE host compartments 0 / 5 / 8 / 9 of the 813k-cell 48 hpf partition (frozen membership; both arms identical except gene selection). On no target does dropping HVG lose purity by more than σ ≈ 0.069.

The dramatic case is Pancreas: HVG smeared it to purity 0.58; all-genes isolated it cleanly at 0.99 — same cells, same everything, only the gene set differs.

what we tested

One coarse Leiden res-0.1 partition of the 813,782-cell 48 hpf ZSCAPE cohort, membership frozen and reused verbatim so every arm branches from identical compartments. The named recovery targets are buried minorities (0.3–2% of cells) inside four host compartments. For each host we recluster twice — Arm A recomputes a fresh per-compartment 2000-gene HVG set; Arm B uses all expressed genes — with everything else held identical (PCA≤50, 15-NN, local Leiden 0.8, SEED=7). Ground truth (control-vote cell-type labels) enters at scoring only.

Purity & F1 at a glance

The mechanism — geometric, not feature-selection

The obvious explanation would be “HVG dropped the discriminating markers.” It didn’t. The primary markers were already in the HVG set: pancreas ins (HVG rank 3), gcga (4), sst2 (25); intestine cdx1b (289). HVG had them and still smeared pancreas — so selection isn’t what surfaced them.

What actually happens: in a mixed compartment, variance-ranked HVG axes are dominated by the majority tissue (CNS in comp 5), and the tiny target island gets absorbed into those axes. Keeping all genes preserves the full-transcriptome distance, in which the target’s complete program stays distinct even though no single ranked axis is “about” it. The effect is geometric — a property of the distance, not of which features you selected.

The honest caveat — recall, not a footnote

  • On the faintest programs (Blood, Ear/otic) no-HVG holds purity but fragments the tissue into several pure sub-clusters — same purity, worse recall. Blood F1 0.85→0.69; otic F1 0.47→0.31.
  • So HVG’s residual value is consolidating faint signals into one cluster, not discriminating them. That is a real limit on “just drop HVG,” not a rounding error — for rare, low-count programs, HVG still buys recall.

What this means for Pillar 1 — open question, not a rewrite

The recursive recipe credits the local HVG recompute as the load-bearing mechanism that surfaces buried tissues. This run says the recovery is geometric, not feature-selection — the buried markers surface in the all-genes neighbor structure regardless. That is a genuine tension with the documented mechanism story, and worth the team’s attention. Flagging it as an open question, not a settled rewrite of Pillar 1 — this is one run, one dataset (ZSCAPE), and the faint-program recall caveat is unresolved.

origin · first act · below the fold

Where this started — comp-8 (MiniFin), the shared-program worst case

The question began on a single compartment: MiniFin comp-8 — the frozen 1,537-cell / 12-leaf ionocyte + goblet set (control-vote GT). It is a shared-program, already-separated 2-type case: the two cell types are transcriptionally close and already split, so there is little for feature selection to do. Here HVG and no-HVG were a near-tie on geometry, and HVG held a modest edge on the fine biology — which is what made us predict that the distinct-program compartments above would be where HVG finally bit. They weren’t.
