Why the graph network won

We asked five models to predict what happens when you knock out a gene. Four of them see only which genes you perturbed. One also sees how the genes are wired together. That single difference decides everything.

In a gene-regulatory network, a perturbation doesn't stay local — knocking out one gene ripples outward along regulatory edges to change its neighbours, and their neighbours in turn. A model given only a dose vector (Ridge, MLP, XGBoost) can learn these ripples only by memorising examples: it has to have seen that gene perturbed before to know what it does. A graph neural network is given the wiring itself, so it predicts an effect by passing messages along the known edges — the same way the biology actually propagates. When the test asks about a gene the model has never seen perturbed, memorisation has nothing to fall back on, but message-passing simply routes the effect through the network. The graph is an inductive prior: built-in knowledge of how influence flows, rather than a pattern to be rediscovered from data.
