Epicule · MiniEpi v2

Why the graph network won

Before trusting a model on real zebrafish data, we built a synthetic organism where the ground truth is known exactly — and used it to ask a sharp question: when a model predicts the effect of a genetic perturbation, is it learning how the biology is wired, or just memorising what it has seen? One model architecture answered that question decisively.

1A synthetic organism, wired by hand

MiniEpi v2 is a miniature gene-regulatory network: 20 genes arranged in 4 modules of five (Alpha, Beta, Gamma, Delta), connected by 75 directed regulatory edges — 63 that activate their target and 12 that repress it. The wiring isn't random: it's seeded with the same motifs real genomes use — bistable toggle switches, feed-forward loops, autoregulation and competitive binding.

Every edge is a tunable “volume knob.” Its strength follows a Hill function — an S-shaped dose–response curve — so a regulator's influence on its target is graded and nonlinear. All 265 of these kinetic parameters were tuned by an evolutionary optimiser (CMA-ES) until the network had two properties we need: a stable wild-type resting state, and single-gene knockouts that each produce a distinct, well-separated outcome. The result is a fully deterministic simulator we can run to steady state.

2The predictive task

From this organism we generate 2,020 perturbations: single-gene knockouts, knock-downs and over-expressions, plus double and triple knockouts and random multi-gene “drug” combinations. For each one we run the simulator to convergence and record how far every gene's expression has shifted from wild-type — a 20-number change vector we call the delta.

Every model gets the same job: read the perturbation, predict its 20-number delta. Nothing about the trajectory in between — just the perturbation in, the final change out.

One prediction, start to finish

3What each model is given

Four of the five predictors — Ridge regression, an MLP, XGBoost, and a nearest-neighbour lookup — receive only a dose vector: 20 numbers saying which genes were perturbed and how hard (1.0 = untouched, 0.0 = knockout, 5.0 = strong over-expression). That's it. They see which genes changed, but nothing about how the genes relate to one another.

The graph neural network receives that same dose vector plus the wiring itself — all 75 edges, each carrying its sign, strength and Hill parameters. Crucially, no model is ever told the trajectory, the wild-type levels, the gene names, or which “type” of perturbation a sample is. The only extra thing the GNN holds is the map of who regulates whom.

4What they're expected to learn

To predict a delta well, a model has to internalise how a perturbation propagates: knock out one gene and the effect ripples along its edges to change its neighbours, and their neighbours in turn — bending back through feedback loops and combining nonlinearly when several genes are hit at once (epistasis).

A dose-only model can only approximate this by seeing enough examples to interpolate the pattern — it has to have observed a gene perturbed before to know what perturbing it does. The GNN doesn't have to rediscover the wiring from data, because the wiring is handed to it: it predicts an effect by literally passing messages along the known edges, the same way the biology propagates. That built-in structure is called an inductive prior — and it only earns its keep when the task moves outside what was memorised.

5The hardest test — a knockout never seen

So we designed the test that separates understanding from memorisation. We removed one gene from every training example — the model never once sees it perturbed — then asked all five models to predict what happens when you knock it out. For a dose-only model this is a column it has no signal for; it can only guess. For the GNN, the gene is still a node in a known graph, still receiving influence from neighbours it has seen. This is the moment the inductive prior pays off — or doesn't.

The test — predict a knockout the model has never seen

Gene A5 was held out of all training. A dose-only model has no signal for it → guesses. The GNN receives influence from its known neighbours → predicts it.

6The result

On the held-out knockout, every dose-only model collapses toward zero — Ridge and Nearest-neighbour even go negative, worse than guessing. The graph network scores 0.90. It is the single cleanest piece of evidence in the whole benchmark that encoding the network's topology is what lets a model generalise to biology it was never trained on.
