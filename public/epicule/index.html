A graph neural network as a gene-regulatory world-model

The network below is a synthetic gene-regulatory network — 20 genes in four regulatory modules, wired by 75 signed edges (Hill-kinetic activation / repression). The GNN reads a perturbation, passes messages along these edges, and predicts how every gene's expression shifts. It's benchmarked head-to-head against a "Canonical 9" panel (naïve baselines, Ridge, MLP, XGBoost) on ~2,020 perturbations.
